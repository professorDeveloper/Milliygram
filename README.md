# Milliygram

**Based on Radolyn & Telegram**

A Java-based Android messaging app forked from the *drlko* repository and inspired by Telegram’s clean UI/UX. Built as a contest entry, Milliygram demonstrates core chat functionality with a native Java implementation.

---

## 🚀 Features

* **Forked Base**: Built upon the drlko codebase for rapid development.
* **Telegram-Inspired UI**: Clean, intuitive layouts and animations.
* **Contest Entry**: Developed under a tight deadline to showcase rapid prototyping.
* **Fake admin u can be fake admin as any channel as u want
* **Fake premium u can use premium features as much as u want without any purchases

## 🔗 Getting Started

1. **Clone the repository**:

   ```bash
   git clone https://github.com/professorDeveloper/Milliygram.git
   cd Milliygram
   ```
2. **Open in Android Studio** and let Gradle sync.
3. **Run** on an emulator or connected device.
